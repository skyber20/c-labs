## Постановка задачи

Составить программу выполнения заданных преобразований арифметических выражений с применением деревьев. Преобразование выражения в дерево осуществляется методом shunting yard (Дейкстры). Операнды - целые числа и переменные произвольной длины.
Программа должна вводить и печатать выражения в исходном (текстовом) виде, преобразовывать их в деревья, выполнять заданные преобразования путем обращения к подпрограммам и печатать результаты в виде дерева и в текстовом представлении.

## Вариант задания

**Вариант 20**. Упрощение многоэтажной дроби по правилам:
1. ```(a / b) / c -> a / (b * c)```
2. ```a / (b / c) -> (a / b) * c```

---

## Описание реализации
- Лексический анализ: Реализован токенизатор, поддерживающий переменные произвольной длины и распознавание контекста унарного минуса (помечается символом ~).
- RPN: Использование алгоритма "Shunting Yard" Дейкстры для перевода инфиксной записи в постфиксную (ОПН) с учетом приоритетов и правоассоциативности оператора степени ^.
- Структура данных: Бинарное дерево выражений, где узлы-операторы хранят указатели на левое и правое поддеревья, а листья - операнды.
- Трансформация (Вариант 20): Рекурсивный обход дерева снизу вверх. Преобразование выполняется путем перевешивания указателей.
- CLI
