## Постановка задачи

Рекурсивный обход указанного каталога и вывод на экран полных путей поддиректорий

## Описание работы

Скрипт в качестве аргумента присылает путь к каталогу. Сначала проверяется количество аргументов и что переденный путь существует и является директорией. Затем путь преобразуется в абсолютный.

Далее функция `walk` рекурсивно просматривает содержимое каталога. Если найденный элемент является директорией, его полный путь выводится на экран, после чего для него снова вызывается функция `walk`

## Запуск

```bash
chmod +x script.sh
./script.sh <каталог>
```
