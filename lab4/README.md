## Постановка задачи

Построить упорядоченное дерево для хранения и поиска элементов с уникальными строковыми ключами и вещественными значениями. Ключ - непустая последовательность латинских букв не более чем из 6 символов. Ключи упорядочиваются лексикографически.

## Вариант задания

**Вариант 20**. Красно-черное дерево.
Реализовать операции:
1. Добавление узла по ключу (с балансировкой)
2. Удаление узла по ключу (с балансировкой)
3. Печать дерева (с маркировкой цвета узлов)
4. Поиск значения по ключу

---

## Описание реализации
- **Структура данных**: Красно-черное дерево с использованием фиктивного узла `NIL` (черного цвета) в качестве листьев. Это упрощает реализацию алгоритмов балансировки
- **Балансировка**: Реализованы левые и правые повороты, а также функции восстановления свойств дерева после вставки (`insertFixup`) и удаления (`deleteFixup`)
- **Удаление**: Реализовано полноценное удаление узла с поиском преемника и перевешиванием поддеревьев через функцию `transplant`
- **Память**: Реализована рекурсивная очистка памяти всех узлов дерева
- **CLI**: Поддерживает два режима: интерактивный (через консоль) и файловый (чтение из файла и запись в файл)

### Запуск:
Для автоматизации сборки используется `Makefile`.

**Запуск в консольном режиме:**
```bash
make main
```

**Запуск в файловом режиме:**
```bash
./main input.txt output.txt
```

**Запуск тестов:**
```bash
make tests
```

**Очистить файлы:**
```bash
make clean
```
